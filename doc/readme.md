레이다 센서의 동작 상태, 제스쳐 인식 히스토리 등을 보여주고, IOT기기 동작 할당 및 등록 등을 하는 사용자 친화적 웹 대시보드 UI를 디자인해볼겁니다.
지금 아이디어를 제시할테니 구체화하여 마크다운 형식으로 복붙하기 편하게 정리합니다.

구동 환경
- 라즈베리파이 5

레이다 센서
- 레이다 센서에서 패킷을 wifi를 사용해 같은 네트워크에 연결된 파이5에 전달함
- asio를 사용해서 c++로 패킷을 실시간으로 읽어오는 로직은 현재 존재함

제스쳐 인식
- 현재 10개의 클래스로 구분된 제스쳐를 인식하는 신경망을 개발 중(0번은 제스쳐 없음 클래스), 지금 6개의 클래스를 구분하는 신경망은 개발 완료
- ncnn라이브러리를 통해 네이티브로 연산함. 연산량은 높지않고 20fps로 실시간 동작함을 확인

백엔드 서버
- 레이다 센서와의 통합 및 기존 ncnn라이브러리를 이용하기 위해 c++로 서버를 만들예정.
- c++ drogon라이브러리를 활용함.
- mqtt를 사용해서 파이의 homebridge와 통신할 예정.
- 추가적으로 ir remote제어 기능을 제공

웹 대시보드
- 사용자는 파이의 ip와 포트번호를 통해 웹 ui에 접속 가능(프로토타입은 일단 그럼)
- 사용자 친화적인 UI를 만들며 모바일 환경을 지원함
- 기능
	- 지금까지 인식된 제스쳐의 히스토리 제공
	- 연결된 레이다 센서의 실시간 상태 제공
	- 현재 homebridge에 등록된 iot장치들의 목록, 실시간 상태, 사용가능한 동작등을 표시
	- ir remote 신호를 등록하고 제스쳐에 바인딩
	- 레이다의 제스쳐 클래스와 iot장치의 동작을 바인딩
	- iot장치를 검색하고 등록(더미로 만들거임)
